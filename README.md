# 면접 치트키 · 새싹(SeSAC) AI·PM

새싹 4개 캠퍼스(금천·용산·양천) 면접에 바로 쓰는 예상 질문·첫 문장·키워드·답변 예시를 한 화면에서 보는 단일 페이지 앱입니다. 노션 페이지에 임베드하거나 휴대폰에서 바로 열어 쓰도록 만들었습니다.

- 배포 주소: https://r2w8jp5hmn-cyber.github.io/sesac-interview-kit/
- 파일: `index.html` 하나 (외부 라이브러리 없음 · Pretendard 웹폰트만 CDN, 실패 시 시스템 한글 폰트로 대체)
- 노션 임베드: `/embed https://r2w8jp5hmn-cyber.github.io/sesac-interview-kit/`
- 임베드 높이: 노션 임베드 블록 기본 높이는 320px이라 카드가 접혀 보입니다. 하단 핸들을 아래로 끌어 **600px 이상**으로 늘려 두면 질문 하나를 펼쳐도 답변까지 한 번에 보입니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 구조도 | `과거 이력 → 강점 발견 → 현실적 고민 → 커리어 전환 결심 → AX·운영기획 / AI PM·PO → 새싹 교육 → 실무 취업` 흐름 + "왜 창업 대신 취업" 최종 답변 전문 |
| 금천 · AX | 업스테이지 K-AI AX 컨설턴트 · 레벨테스트 11/30~12/1 · 비대면 면접 12/3~4 |
| 용산 · PM | 리멤버 × 러닝스푼즈 AI Agent PM/PO · 테스트 12/7 · 면접 12/8~9 |
| 양천 · AI·데이터 | 핀인사이트 · 면접 12/10(목) 10:40 · 발표 12/11 |

각 질문 카드를 누르면 ① 첫 문장(앵커) ② 키워드 3개 칩 ③ 예상 답변 예시가 펼쳐집니다. 한 번에 하나만 열립니다.

## 수정

- 카드 안 `수정` → 문구를 고치고 `저장`하면 `localStorage`(`sesac-interview-kit:v1`)에 저장됩니다. `기본값`은 그 카드만, 하단 `수정 내용 초기화`는 전체를 되돌립니다.
- 저장은 **그 기기 브라우저에만** 됩니다. PC·폰·노션 앱이 서로 동기화되지 않으니, 계속 쓸 문구는 저장소의 `index.html` 데이터(`CAMPUSES`)를 고쳐 커밋하는 편이 안전합니다.

## 문구 고치는 곳

`index.html` 안 `var CAMPUSES = [...]` 의 각 캠퍼스 `qs` 배열에서 `q`(질문) · `a`(첫 문장) · `k`(키워드 3개) · `e`(답변 예시)를 고치고, 전체 답변은 `var ANS_FULL` 을 고칩니다.
